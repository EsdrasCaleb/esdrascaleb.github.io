## 🚀 Local Development

To run this website locally on your machine, follow these steps:

1. **Clone the repository:**
```bash
   git clone [https://github.com/EsdrasCaleb/esdrascaleb.github.io.git](https://github.com/EsdrasCaleb/esdrascaleb.github.io.git)
   cd esdrascaleb.github.io

```

2. **Install dependencies:**
```bash
bundle install
```


3. **Serve with Jekyll:**
```bash
bundle exec jekyll serve

```


*Access `http://localhost:4000` in your browser.*
